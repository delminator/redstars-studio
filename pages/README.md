# pages/ — project and funding pages

`project.md` (tab « Présentation ») and `funding.md` (tab « Financement »,
your tiers and goals are added below it) — both optional, shown in the
subscription dialog and on the public page `/apps/<app>/`.

Markdown only, 64 KiB max: `#`/`##`/`###` titles, paragraphs, `-`/`1.` lists,
`**bold**`, `*italic*`, `` `code` ``, `[links](https://…)` (https and mailto
only). **No HTML** (refused), no images.

Only these two file names are read; this README is ignored by the platform.
Full guide: `docs/STORE.md`.
